# Security

Report vulnerabilities using GitHub's private vulnerability reporting on this repository. Do not publish clipboard contents or credentials in an issue.

Clipboard history is stored locally in SQLite under `~/Library/Application Support/Clipglass/`. The directory is created with owner-only permissions and the database with mode 0600. The database is not encrypted by the app. FileVault can protect disk contents while your Mac is powered off; software running as your user can read your history.

The app skips clipboard data marked concealed, transient, or autogenerated by the source. Unmarked secrets cannot reliably be detected. Pause capture before copying sensitive content and clear history when appropriate. SQLite secure deletion and WAL checkpointing remove deleted live records, but cannot erase filesystem snapshots or backups.

Direct paste uses Accessibility to validate the original focused editable element before sending Command–V to its process. Secure fields and unknown/non-editable targets are rejected. Compatibility depends on the target app's accessibility implementation; this is not a security boundary against malicious applications.

There is no network client, analytics, cloud sync, or automatic update service. Release downloads are provided by GitHub. Only the latest release receives fixes.
